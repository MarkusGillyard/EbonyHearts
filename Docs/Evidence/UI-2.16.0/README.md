# Interface before and after: Ebony Hearts 2.16.0

Real frames from the Unreal game, captured offscreen from the editor build at the resolution shown in
each image's label, the two sides from the same scripted flows where those existed.

- **Before:** 2.15.0, commit `d2c021c`, 1920 x 1080, captured 31 October 2026 before any change.
- **After:** 2.16.0, commit `3e7b3eb`, 1920 x 1080.

These are current-build comparisons, not the historic Godot version.

`01` to `12` are pairs. The flows' scripts picked different fighters and stages at random between runs,
and two of the baseline flows were stale (they missed Extras), so `10` compares a settings page of
each build rather than the same page.

`13` to `19` have no "before": the tower, boss, Grandmaster, results, continue and ending screens were not reached
by the baseline flows, and nothing was recaptured from the old build afterwards. `20` is the same five
moments at every required resolution.

`21` is from 2.16.1, commit `17f243a`: the finisher's new name on a real finisher.
